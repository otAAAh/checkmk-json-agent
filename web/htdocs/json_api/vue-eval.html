cmk-frontend-vue evaluation harness

Binds to this site's own cmk-frontend-vue bundle (no Vue is shipped in the MKP) to try the native Checkmk Web Components live. Internal & unversioned — evaluation only.

Mount a component

Pure components (cmk-icon, cmk-dynamic-icon, cmk-rnbw) have the simplest contract. cmk-form-spec needs the full generated form-spec schema and will likely error with a stub — that failure is itself a useful eval finding.

Bundle resolution

Mirrors cmk/gui/htmllib/html.py: resolve src/main.ts from .manifest.json, recurse imports for CSS, inject stylesheets + the module script.
